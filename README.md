🔍 LIKE Pattern Cheat Sheet
Pattern   Meaning
'P%'✅   Starts with P
'%P'✅   Ends with P'
%P%'✅ Contains P

Examples
'A%' → Amit, Alex
'%son' → Jackson, Wilson
'%an%' → Anand, Ryan

📊 Aggregate Functions
Function     Purpose
COUNT()    Count records
SUM()        Total value
AVG()         Average value
MAX()        Highest value
MIN()         Lowest value

✅ ASC → Lowest to Highest
✅ DESC → Highest to Lowest

🤝 JOIN Memory Trick
🟢 INNER JOIN → Only matching rows
🟡 LEFT JOIN → Keep all rows from the LEFT table
🟠 RIGHT JOIN → Keep all rows from the RIGHT table
